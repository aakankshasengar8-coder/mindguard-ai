# MindGuard AI

MindGuard AI is an early burnout detection system designed for campus communities.
It uses Artificial Intelligence to predict burnout risk based on daily habits.

## Problem Statement
Students often experience stress and burnout silently.
There is no early warning system to detect burnout before it becomes critical.

## Solution
MindGuard AI analyzes daily inputs such as sleep hours, study hours, mood, and focus level
to generate a burnout risk score with explainable insights.

## Features
- Daily habit tracking
- Burnout risk score
- Explainable AI insights
- Personalized preventive suggestions
- Secure user authentication
